# CampusOps — 校園設施巡檢與派工平台

一個提供大學總務處、校園設施管理單位與維修廠商使用的 B2B／政府型營運系統 Demo。將 GIS 校園地圖、行動巡檢、異常通報、工單派發、維修追蹤與稽核報表整合在同一平台。

純 HTML / CSS / JavaScript 打造，無框架、無建置流程，可直接用任何靜態伺服器開啟。

## 快速開始

```bash
python3 -m http.server 8080
# 開啟 http://localhost:8080/index.html
```

登入帳密已預填（工號 `A12345` / 密碼 `campus2026`），可於登入頁選擇要示範的身分：

- **總務處管理者** — 完整功能：Dashboard、GIS 地圖、工單派發與驗收、稽核報表
- **巡檢人員** — 巡檢任務、行動巡檢表單
- **維修技工／外部廠商** — 僅能看到指派給自己的工單，可回報進度與上傳完工照片
- **校內通報者** — 僅能填寫問題通報

四種身分之間可隨時在右上角切換；切換到沒有權限的頁面會顯示「權限不足」畫面，這是刻意示範的行為，不是錯誤。

## 主要頁面

| 頁面 | 說明 |
|---|---|
| `index.html` | 登入 |
| `dashboard.html` | 營運總覽（待處理／逾期／高風險／已完成、SLA、趨勢圖、異常排名） |
| `map.html` | GIS 校園地圖（6 棟建築、6 種設施圖層、風險等級篩選） |
| `inspections.html` | 巡檢任務列表 |
| `inspection-form.html` | 行動巡檢表單（390px 手機版） |
| `workorders.html` / `workorder-detail.html` | 工單列表與詳情／派工／驗收 |
| `reports.html` | 稽核與報表，可匯出 CSV／政府稽核格式／PDF |
| `report-issue.html` | 校內通報者填寫問題通報 |

## 展示資料

所有校園、人員、工單資料皆為虛構，不代表任何真實學校或機構。資料存於 `localStorage`，可在側邊欄「重設 Demo 資料」還原成初始內容。頁面右上角的「測試狀態」連結可切換 `loading` / `error` / `empty` 三種畫面狀態，方便檢視。
